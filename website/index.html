Welcome to My Cloud Website

About This Project

This website was created for a university cloud computing project. It demonstrates how a static website can be hosted using Amazon Web Services.

AWS Services

The project uses the following services:

  • Amazon S3 - Stores the website files.
  • Amazon CloudFront - Delivers website content worldwide.
  • Amazon Route 53 - Manages DNS and domain names.

Project Goal

The goal is to provide a reliable and accessible website using cloud infrastructure managed with Terraform.
